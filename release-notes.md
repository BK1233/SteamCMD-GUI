# v2.0.0 - The Big Refactor & Feature Update!

This is a massive update that brings a host of new features and improvements to the SteamCMD GUI, making it more powerful, easier to use, and more reliable than ever before.

## ✨ Highlights (What's New?)

*   **Automatic Server Updates:** A new "Updates" tab has been added, allowing you to check for and install game server updates with a single click. No more manual checks!
*   **Modern Look & Feel:** The entire application has been given a sleek, modern dark theme and a new set of icons for a cleaner and more visually appealing experience.
*   **Your Settings Are Saved!:** The app now remembers your settings, such as RCON connection details and backup paths, so you don't have to re-enter them every time you open it.

## 🛠️ Under the Hood (For the Tech-Savvy)

*   **Major Code Refactoring:** The application's codebase has been completely reorganized to be more robust and easier to maintain. We've separated logic for RCON, Backups, Workshop, Server Management, and Updates into their own dedicated modules. This means a more stable app and a better foundation for future features!

We're excited for you to try out this new version! As always, we welcome your feedback.
